---
name: Active-drive map-first layout
description: Interaction rule for the active driving screen and its persistent controls.
---

During an active drive, the map is the primary surface. Keep live time/distance, SOS, End Trip, dashcam, audio, and essential navigation status immediately available, but place score, sharing, and secondary trip detail behind an explicit More controls disclosure.

**Why:** Drivers asked for a full maps page and found the previous Drive Safely menu too dominant. Safety-critical actions cannot disappear, so reducing secondary content is safer than removing controls.

**How to apply:** Start every new drive collapsed, avoid menu-style headings, preserve large touch targets, and ensure expanding details never changes navigation or trip state.
